# Hangman Game

A simple Hangman game developed using Python.

## Description

This is a console-based Hangman game where the player tries to guess a hidden word one letter at a time.

## Features

- Random word selection
- Letter guessing
- Tracks incorrect guesses
- Displays the progress of the word
- Win or lose result

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open a terminal or command prompt.
3. Run the program using:

```bash
python hangman_game.py
